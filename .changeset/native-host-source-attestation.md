Propagate trusted original model-source identity to embedding-host tools through a purpose-bound variant of native signed delegation. Ordinary OAuth connection authorization remains separate and mandatory. The API validates exact scope, current attempt, immutable source receipt, target, canonical arguments and OAuth credential before invoking an optional per-call host registration hook. Public metadata and ordinary delegated bearers cannot impersonate this evidence; it grants no business authority. No migration or activation is included.
