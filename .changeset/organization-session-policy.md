An organization that a bound `organizationGovernance` port governs gets a session policy (migration 1018, `@opengeni/contracts/organization-session-policy`): whether people may attach files in its workspaces' sessions, and which generic tool families (`shell`, `codemode`, `browser`, `computerUse`) its sessions never receive. The governed default (attachments off, all four families denied) is stored at every governed entry point that can start work (organization creation, host commands, session creation, message admission, schedule and automation-trigger create/update/resume/run) and by `bootstrapWorkspace({ governedSessionPolicy: true })`, so the worker, which reads a missing row as stock, never runs a governed organization's work without it. The runtime may only insert the governed default (an INSERT row policy) and never update or delete it. A host replaces the policy with `PUT /v1/host/organizations/:id/session-policy` (`{ policy, operationId, expectedRevision }`, mutation `session_policy.update`) through a SECURITY DEFINER routine whose runtime grant is withheld for one release, so until then the command answers `503 HOST_SESSION_POLICY_UNAVAILABLE`; replays are idempotent per operation id and body digest (`409 SESSION_POLICY_OPERATION_CONFLICT`, `409 SESSION_POLICY_REVISION_CONFLICT`). Refusals are `403 ATTACHMENTS_DISABLED` (uploads, upload completion, file attachments, knowledge drops, session file writes, file-carrying schedule and trigger templates) and `403 SESSION_TOOL_FAMILY_DENIED` (Codemode, browser, computer, screen-control, machine enrollment, terminal, session filesystem and git routes); denied tools are never registered by the first-party MCP server and are removed from every turn's catalog in the worker, which also mints no Codemode bearer for them and refuses file-carrying schedules and triggers when they fire. The workspace-scoped client config reports `fileUploads.enabled: false` and the console hides attach controls. Ungoverned organizations, and deployments without the port, are unchanged.
